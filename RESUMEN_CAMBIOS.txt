================================================================================
🔐 AUTENTICACIÓN POR ROLES - RESUMEN DE CAMBIOS
================================================================================

OBJETIVO:
Implementar un sistema de autenticación basado en roles usando JWT tokens
donde se modifican los tokens para incluir información de rol y se protegen
las rutas según el nivel de acceso.

================================================================================
📝 CAMBIOS PRINCIPALES
================================================================================

1. MODELO NUTRITIONIST (src/models/Nutritionist.js)
   ✅ Agregado campo: this.role = data.role || "nutritionist"
   
2. ENDPOINT LOGIN (src/app/api/auth/login/route.js)
   ✅ Cambio de "nutritionistId" → "id"
   ✅ Agregado "role" al payload del JWT
   
3. NUEVO ENDPOINT (src/app/api/auth/me/route.js)
   ✅ Verifica el token del cookie
   ✅ Retorna: { id, email, name, role, specialization }
   
4. PANTALLA ADMIN (src/app/admin/page.js)
   ✅ Dashboard exclusivo para usuarios con rol "admin"
   ✅ Valida acceso antes de renderizar
   ✅ Redirige a /dashboard si no es admin
   
5. COMPONENTE PROTEGIDO (src/components/ProtectedRoute.js)
   ✅ Componente reutilizable para proteger rutas
   ✅ Verifica rol requerido

================================================================================
🔄 ESTRUCTURA JWT MODIFICADA
================================================================================

ANTES:
{
  "nutritionistId": "507f1f77bcf86cd799439011",
  "email": "user@example.com",
  "name": "Usuario",
  "specialization": "Nutrición"
}

AHORA:
{
  "id": "507f1f77bcf86cd799439011",
  "email": "user@example.com",
  "name": "Usuario",
  "specialization": "Nutrición",
  "role": "admin"  ← ¡NUEVO!
}

================================================================================
🚀 CÓMO USAR
================================================================================

Para crear un usuario admin:
  db.Nutritionist.updateOne(
    { email: "admin@example.com" },
    { $set: { role: "admin" } }
  )

Para acceder al dashboard admin:
  1. Ir a http://localhost:3000/admin
  2. Si eres admin → Ves el dashboard
  3. Si no → Eres redirigido a /dashboard

Para proteger otras rutas:
  import { ProtectedRoute } from "@/components/ProtectedRoute"
  
  export default function AdminPage() {
    return (
      <ProtectedRoute requiredRole="admin">
        <div>Solo Admin</div>
      </ProtectedRoute>
    )
  }

================================================================================
📊 FLUJO DE AUTENTICACIÓN
================================================================================

Login → JWT generado con role → Stored en cookie → 
Usuario accede /admin → Frontend verifica role → 
Si role=="admin" → Muestra admin dashboard →
Si no → Redirige a /dashboard
